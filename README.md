# Sobel Edge Detection Using Numerical Differentiation

## About the Project

This project explores the application of numerical differentiation in digital image processing through the Sobel edge detection operator.

The implementation uses Python, NumPy and OpenCV to calculate image gradients and identify edges in grayscale images.

## Objectives

- Understand numerical differentiation in image processing.
- Implement the Sobel operator using NumPy.
- Compare forward, backward and central difference methods.
- Study the effect of threshold selection.
- Analyse sensitivity to Gaussian noise.
- Investigate Gaussian smoothing as a preprocessing technique.

## Technologies Used

- Python
- NumPy
- OpenCV
- Matplotlib
- Google Colab

## Experiments

1. Manual Sobel implementation.
2. Threshold-based edge detection.
3. Verification against OpenCV.
4. Gaussian noise sensitivity analysis.
5. Comparison of numerical differentiation methods.
6. Gaussian smoothing before edge detection.

## How to Run

Open `Sobel_Edge_Detection.ipynb` in Google Colab and execute the notebook cells sequentially. Upload an input image when prompted.
